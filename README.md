## 💼 Dự án nổi bật

### [PCSTORE] — Website thương mại điện tử bán linh kiện PC
* **Thời gian:** 08/2026 – 10/2026 (Dự án học tập tại Đại học Duy Tân)
* **Mô tả:** Website thương mại điện tử hướng đến việc kiểm tra tương thích phần cứng và tư vấn cấu hình PC.
* **Vai trò & Nhiệm vụ:** 
  * Tham gia phát triển giao diện Frontend, xử lý cấu hình gói sản phẩm và kết nối API hệ thống.
  * Phân tích yêu cầu, xây dựng User Stories và kiểm thử thủ công các luồng giao diện, đặt hàng, tìm kiếm và lọc sản phẩm.
* **Công nghệ:** Node.js, Express, React, Vite, JavaScript, PostgreSQL/SQL Server, npm.
